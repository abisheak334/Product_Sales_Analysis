The Product Sales Analysis Dashboard is an interactive Power BI report developed to analyze product sales performance and identify key business trends. The dashboard provides insights into total sales, revenue, quantity sold, profit, product-wise performance, category-wise sales, and sales trends over time.

The project uses Power Query for data cleaning and transformation and DAX for creating calculated measures and KPIs. Interactive charts, slicers, and filters enable users to analyze sales performance based on products, categories, regions, customers, and time periods.

Key Features:

📊 Total sales, revenue, profit, and quantity sold
🛍️ Product-wise sales performance
📦 Category and sub-category analysis
📈 Monthly/yearly sales trends
🌍 Region-wise sales analysis
👥 Customer-wise sales insights
💰 Profit and profit-margin analysis
🔝 Identification of top-performing products
📌 Interactive KPIs, slicers, and visual reports
